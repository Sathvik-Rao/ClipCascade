ClipCascade
===========

A lightweight utility to sync clipboard content seamlessly across devices
with privacy and encryption.

Project:   https://github.com/Sathvik-Rao/ClipCascade
Releases:  https://github.com/Sathvik-Rao/ClipCascade/releases
Issues:    https://github.com/Sathvik-Rao/ClipCascade/issues

After installing, ClipCascade will be available from the Start Menu, the
Desktop shortcut, and will auto-start on login (it lives in the system tray).
